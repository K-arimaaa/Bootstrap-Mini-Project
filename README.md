# 🎵TuneWave - Music Platform

TuneWave is a simple and responsive music platform website. This project was created as a basic web development project using very basic HTML, CSS, JavaScript, and Bootstrap.

## 📌Features

- Simple and responsive navigation bar
- Home page with featured songs
- Popular songs page
- Artists page
- Playlist page
- About page
- Basic JavaScript alert functionality
- Responsive design using Bootstrap
- Footer section on all pages

## 📄Pages

1. Home
2. Songs
3. Artists
4. Playlist
5. About

## 🛠️Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
